# MindBase Plugin

> Karpathy's LLM-Wiki pattern as a Claude Code plugin. Build and maintain a persistent, AI-tended research wiki without leaving your terminal.

## What it does

- **`/mb:init <name>`** — Scaffold a new research project (v2 layout)
- **`/mb:contribute <text>`** — Add a thought, paste, URL, or PDF. AI calibrates output volume
- **`/mb:build`** — Synthesize `context.md` from all contributions (atomic, safe)
- **`/mb:ask <q>`** — Cited answer using hybrid search + graph expansion
- **`/mb:lint`** — Health check (orphans, contradictions, stale claims, gaps)
- **`/mb:status`** — Project dashboard
- **`/mb:research <topic>`** — Deep research (web + wiki + synthesis)
- **`/mb:daily-brief`** — Today's brief from all contributors
- **`/mb:migrate`** — One-time legacy → v2 layout conversion
- **`/mb:new-project`** — Interactive template-driven init

## Install

> **Lokyy Brain v2 note — the plugin runs the upstream npm package.** `.mcp.json` starts the MCP server with `npx -y mindbase-mcp`, which downloads the upstream MindBase release from npm. It does **not** contain the Lokyy Brain v2 changes (for example slug and project-id validation, the HTTP transport with access profiles, or SSRF protection for URL fetches). The Lokyy Brain v2 packages are private and are not published to npm. To use the fork's MCP server, build `apps/mcp` from this repository and point your MCP client at `apps/mcp/dist/cli.js` (stdio) or run `apps/mcp/dist/http.js` (see `docs/self-hosting-mcp-http.md`).

Via the official marketplace (once available):
```bash
/plugin marketplace add mindbase
/plugin install mindbase@mindbase
```

Local development:
```bash
cd apps/plugin
pnpm build
claude --plugin-dir .
```

## Data layout

Each project lives at `~/mindbase-data/projects/<id>/`:

```
README.md             Operations manual + per-project rules (you edit)
context.md            Curated truth (LLM-owned, regenerated by /mb:build)
index.yaml            Auto-generated nav (never edit)
soul.md               Optional identity/mission/voice
sources/
  contributors/<you>/YYYY-MM-DD.md   Append-only daily entries
  research/<slug>.md                  /mb:research output
  raw/<date>/<id>.*                    PDFs, web clips
state/                                 Agent-managed, opaque to build
logs/YYYY-MM-DD.md                     Daily audit trail
artifacts/                             Generated outputs (briefs, exports)
```

## Architecture

- **MCP server** (`apps/mcp/dist`) — 50+ tools (search, ingest, build, lint, ...)
- **Slash commands** (`commands/`) — markdown instructions for the LLM
- **Sub-agents** (`agents/`) — tool-restricted specialists (builder/curator/researcher/...)
- **SessionStart hook** — auto-injects current project's README+context on each session

## Sub-agent security boundaries

| Sub-agent | Can | Cannot |
|---|---|---|
| `builder` | Read + MCP build tools | Edit / Write / Bash |
| `contributor` | Read + MCP contribute tools | Edit / Write |
| `curator` | Read + MCP lint tools | Edit / Write / Bash |
| `researcher` | Web tools + MCP research_save | Edit / Write on existing pages |
| `migrator` | Bash (atomic mv) + MCP migrate | Edit context.md directly |
